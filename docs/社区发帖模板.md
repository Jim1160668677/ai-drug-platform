### 二、产品简介（复赛版）

#### 是什么

**AI 精准药物设计系统** 是一个面向"一人一药"个性化精准医疗的全流程 AI 药物研发平台。系统将多组学数据接入、AI 靶点发现、分子设计、治疗方案优化、临床反馈、联邦学习、合规审计整合到一个可被真实使用的 Web 产品中。

**作品形态**：Web 应用（在线链接 + 源码包，详见飞书问卷私密提交）

#### 面向谁

- 科研院所研究员：多组学数据分析 + AI 靶点发现
- 药企 CRO：老药新用扫描 + 分子设计
- 临床医生：治疗方案评估 + 患者用药反馈
- 医院信息科：联邦学习 + 隐私计算 + 合规审计

#### 完整功能清单

| 八大模块 | 42 项子功能 |
|---|---|
| A. 多组学数据整合 | 6 种数据类型 / 5 种解析器 / Scanpy 单细胞分析 |
| B. AI 靶点发现 | MyGene / MyVariant / ChEMBL 集成 / 分级路由 |
| C. 分子设计与评估 | RDKit / Lipinski 五规则 / 多靶点协同设计 / ADMET |
| D. 并行治疗方案 | 5 种疗法 / 实时反馈 / 患者用药模板 |
| E. 多假设并行 | Hypothesis Sandbox / LLM 假设生成 |
| F. 干湿闭环 | Nextflow / HL7 FHIR R4 / Pinnacle 21 校验 |
| G. 联邦学习与隐私 | DPSGD / Flower / PySyft 框架 / 知情同意 |
| H. ReAct Agent 引擎 | 自研引擎 / 14 个工具 / WebSocket 实时推送 |

#### 用户使用路径

```
登录 → 工作台 → 创建项目 → 上传多组学数据 → 自动解析 →
靶点发现（自动识别 EGFR/B7H3 等候选）→ 老药新用扫描 →
分子库（自动设计 + 类药性评估）→ 治疗方案（自动匹配 + 评分）→
多假设并行（创建并对比）→ 干湿闭环（提交实验数据）→
报告中心（导出 CDISC SDTM/ADaM）
```

创新路径：**ReAct Agent 智能助手** — 用自然语言下达任务（如"分析 EGFR T790M 突变并推荐 3 个候选分子"），Agent 自动 Thought → Action → Observation 循环执行，DAG 任务规划图实时可视化。

- 核心功能：1 条主链路 → **8 大模块 42 子功能 + ReAct Agent**

### 四、产品创作历程

#### 灵感来源

GitLab 联合创始人 Sid Sijbrandij 在 2023 年公开分享了自己的个性化癌症治疗经历。当一个工程师面对癌症时，他能用 AI 做什么？这个问题驱动我开始这个项目。

#### 从想法到初赛 Demo

- **2026-06**：阅读 Sid 的治疗记录，提炼出"极限诊断数据整合 + AI 辅助靶点 + 并行治疗方案"三大核心需求
- **2026-07-04**：完成初赛 Demo，跑通主链路（数据上传 → 靶点发现 → 分子设计 → 治疗方案）

#### 从 Demo 到复赛完整产品

复赛阶段我做了三件关键的事：

1. **功能补全**：基于创意文档 v3.0 全面审计，识别 7 大不完整模块并开发（医疗红线 / DeepDDI / HL7 FHIR / Pinnacle 21 / 数据血缘 / 知情同意 / WebSocket 集成），随后又完成 8 大功能模块的深度增强

2. **架构升级**：自研 ReAct Agent 引擎，让 AI 不只是单点工具，而是能自主规划、调用工具、反思修正的智能体。这是从"AI 辅助"到"AI 协作"的关键跃迁

3. **生产化**：490 测试覆盖、API Key 安全整改、多套部署方案、完整文档体系。让产品从"能演示"变成"能被真实使用"

#### 关键技术决策

| 决策 | 选择 | 理由 |
|---|---|---|
| ReAct 引擎 | 自研 | 医疗场景需要 Guardrail 安全护栏，LangChain 难以深度定制 |
| 数据库 | PostgreSQL + 异步 SQLAlchemy | 满足联邦学习 + 多组学数据需求 |
| 前端 | Next.js 14 + Zustand + XState | 状态管理清晰，SSR 性能优秀 |
| LLM | Agnes 统一接入 | 环境变量注入 Key，符合比赛安全要求 |
| 部署 | Render + Vercel | 免备案海外托管，评审可直接访问 |

#### 遇到的关键问题与解决

1. **API Key 泄露**：GitHub 推送时发现 `seed.py` 硬编码 Agnes Key，立即轮换并改为环境变量注入
2. **WebSocket 鉴权绕过**：TRAE-code-review 识别出 8 个 P0 安全漏洞，逐一修复
3. **react-virtuoso 在 jsdom 不渲染**：测试基础设施层面 mock，保留产品代码不变
4. **ReAct 引擎 max_steps 死循环**：引入 timeout + 步数双重保护 + 上下文压缩

### 六、加分项：技术方案分享

#### 技术栈

- **后端**：FastAPI + SQLAlchemy 2.0 异步 + Pydantic v2 + Alembic + JWT + Fernet
- **前端**：Next.js 14.2.5 + React 18.3.1 + Zustand + XState v5 + reactflow + react-virtuoso
- **AI 引擎**：自研 ReAct Agent（AgentEngine / Planner / Registry / Guardrail / Audit）
- **数据库**：PostgreSQL + Redis + ChromaDB + Neo4j
- **生物信息**：Scanpy / BioPython / RDKit / cyvcf2 / gseapy
- **隐私计算**：Flower / PySyft / DPSGD
- **CI/CD**：GitHub Actions + Docker 多阶段构建

#### 关键实现思路

1. **ReAct 主循环**：`AgentEngine.run()` 实现 Thought → Action → Observation 循环，max_steps + timeout 双重保护，超过限制自动触发上下文压缩
2. **DAG 任务规划**：Planner 将复杂任务分解为有向无环图，前端 reactflow 可视化展示
3. **Guardrail 安全护栏**：医疗红线规则（8 条 FDA 核心 SDTM 规则）+ 输入输出双重过滤
4. **多级权限校验**：target→project→owner / molecule→target→project→owner，防止水平越权
5. **Fernet 加密**：LLM API Key 加密存储，`enc:` 前缀标识密文
6. **Mock/Real 双模式**：所有 service 层依赖抽象接口，USE_MOCK 切换对上层透明
