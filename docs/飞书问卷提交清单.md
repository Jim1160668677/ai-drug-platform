## 八、常见问题

### Q: 评审如何体验真实 LLM 能力？

A: 三种方式：
1. **默认 Mock 模式**：无需 Key，预置真实结构数据（EGFR T790M / B7H3 / Osimertinib 等）
2. **评审测试 Key**：在管理后台「LLM 配置」中填入 `sk-agnes-review-key-for-evaluation-only`，激活后即可真实调用 Agnes LLM
3. **自备 Key**：评审可填入自己的 Agnes / OpenAI Key 进行测试

### Q: 如果部署链接失效怎么办？

A: 立即通过官方渠道（复赛专属交流群）通知主办方，并提供备用链接。本项目准备了多套部署方案：
- 主方案：Render（后端）+ Vercel（前端）
- 备用方案 1：Hugging Face Spaces（后端，16GB RAM 免费层）
- 备用方案 2：本地 Docker Compose 部署（`docker compose -f docker-compose.prod.yml up -d`）

### Q: 如何核验 TRAE 开发过程？

A: 三种核验方式：
1. **Session ID 核验**：在 TRAE IDE 中搜索 6 个 Session ID
2. **GitHub 提交历史**：查看 2026-07-04 ~ 2026-07-19 的完整 commit 历史
3. **文档对照**：`.trae/documents/` 目录下有完整设计文档 + 执行计划 + 测试报告
