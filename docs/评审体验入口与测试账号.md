## 六、常见问题

### Q1: 登录后页面空白？

A: 检查浏览器控制台是否有 CORS 错误。Mock 模式下所有 API 应正常响应，如遇问题请刷新页面或清除 localStorage 后重试。

### Q2: AI 问答响应很慢？

A: 深度洞察模式调用 RAG + 知识图谱，耗时 10-30 秒。如需快速响应，请选择「快速筛查」模式。

### Q3: 数据上传失败？

A: 检查文件格式：
- RNA-seq: CSV / TSV
- 单细胞: h5ad
- VCF: vcf
- FASTA: fa / fasta
- 蛋白质组: CSV / TSV
- 代谢组: CSV / TSV

文件大小限制：单文件 100MB。

### Q4: ReAct Agent 不响应？

A: 检查：
1. 是否已创建会话（点击左栏「+」）
2. 网络是否正常（WebSocket 需要稳定连接）
3. 浏览器是否支持 WebSocket（现代浏览器均支持）
4. 如使用真实 LLM 模式，检查 LLM 配置是否已激活

### Q5: 如何查看审计日志？

A: 登录 founder 账号 → 访问 /admin/audit → 按时间/用户/操作类型筛选。所有操作（登录/数据上传/靶点发现/分子设计等）均会被记录。

### Q6: 部署链接失效怎么办？

A: 立即通过复赛专属交流群通知主办方。备用方案：
- Hugging Face Spaces（16GB RAM 免费层）
- 本地 Docker Compose 部署（见上文「本地部署」）
