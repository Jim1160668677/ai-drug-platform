## 一、产品形态与核心定位

### 1.1 是什么

**AI 精准药物设计系统** 是一个面向"一人一药"个性化精准医疗的全流程 AI 药物研发平台。系统以"AI 模式驱动"理念，将药物研发的干湿闭环、多假设并行、老药新用、CDISC 标准化等核心能力整合到一个可被真实使用的 Web 产品中，覆盖从多组学数据接入、AI 靶点发现、分子设计、治疗方案优化、临床反馈、联邦学习到合规审计的完整链路。

### 1.2 面向谁

| 用户角色 | 典型场景 |
|---|---|
| Founder / 创始人 | 全局决策、紧急干预、跨项目数据分析 |
| 首席研究员 | 模型配置、深度分析、靶点报告审阅 |
| 研究员 | 多组学数据分析、靶点识别、分子设计 |
| 临床医生 | 治疗方案评估、患者用药反馈、靶点报告只读 |
| 数据工程师 | 数据质量监控、系统运维、审计日志 |

灵感来源于 GitLab 联合创始人 Sid Sijbrandij 的个性化癌症治疗经历，旨在让 AI 真正进入药物研发决策回路。

### 1.3 解决的核心问题

1. **多组学数据孤岛**：RNA-seq / 单细胞 / VCF / FASTA / 蛋白质组 / 代谢组数据无法统一接入分析
2. **靶点发现效率低**：依赖人工查文献，缺乏 AI 辅助的证据链构建
3. **分子设计周期长**：缺乏自动化类药性评估与老药新用扫描
4. **临床-科研脱节**：湿实验结果无法快速反馈到干实验模型
5. **多机构协作难**：医疗数据隐私敏感，无法直接共享训练模型
6. **合规审计缺位**：研发过程缺乏 CDISC 标准化输出与全程审计

## 二、完整功能清单与用户使用路径

### 2.1 八大功能模块（42 项子功能）

| 模块 | 子功能 | 关键能力 |
|---|---|---|
| **A. 多组学数据整合** | 数据上传、自动解析、质量评估、数据血缘 | 6 种数据类型 / 5 种解析器 / Scanpy 单细胞分析 |
| **B. AI 靶点发现** | 靶点识别、证据链构建、老药新用、强制深度分析 | MyGene / MyVariant / ChEMBL 集成 / 分级路由 |
| **C. 分子设计与评估** | 分子 CRUD、多靶点协同设计、类药性评估、ADMET | RDKit / Lipinski 五规则 / LLM 辅助生成 |
| **D. 并行治疗方案** | 多疗法组合、疗效监测、动态调整、患者反馈 | 5 种疗法 / 实时反馈 / 患者用药模板 |
| **E. 多假设并行** | 假设沙盒、独立分析、对比分析、自动生成 | Hypothesis Sandbox / LLM 假设生成 |
| **F. 干湿闭环** | 实验数据、流水线触发、断点续跑、CDISC 导出 | Nextflow / HL7 FHIR R4 / Pinnacle 21 校验 |
| **G. 联邦学习与隐私** | 多中心聚合、差分隐私、知情同意、隐私计算 | DPSGD / Flower / PySyft 框架 |
| **H. ReAct Agent 引擎** | 自然语言任务执行、DAG 规划、工具调用、上下文压缩 | 自研引擎 / 14 个工具 / WebSocket 实时推送 |

### 2.2 完整用户路径（评审体验路径）

#### 路径 1：科研全流程（核心路径）
```
登录 → 工作台首页 → 创建项目 → 上传多组学数据 →
触发自动解析 → 进入靶点发现页（自动识别 EGFR/B7H3 等候选靶点）→
对靶点点击「老药新用」→ 进入分子库（自动设计候选分子 + 类药性评估）→
进入治疗方案页（自动匹配疗法 + 疗效/风险评分）→
进入多假设并行页 → 创建假设并对比分析 →
进入干湿闭环页 → 提交实验数据 → 触发 Nextflow 工作流 →
进入报告中心 → 导出 CDISC SDTM/ADaM 报告
```

#### 路径 2：ReAct Agent 智能助手（创新路径）
```
登录 → 进入「AI Agent」工作台 →
新建会话 → 输入自然语言任务（如「分析 EGFR T790M 突变并推荐 3 个候选分子」）→
观察 Agent 自动执行：
  ├─ 步骤 1：Thought → Action: discover_targets
  ├─ 步骤 2：Observation → Thought → Action: design_molecules
  ├─ 步骤 3：Observation → Thought → Action: assess_druglikeness
  └─ 步骤 4：Final Answer（结构化输出）
查看 DAG 任务规划图 / 工具调用气泡 / 进度条 / 流式消息
```

#### 路径 3：管理后台（治理路径）
```
登录 founder 账号 → 管理后台 →
  ├─ LLM 配置：填入 Agnes API Key → 测试连通性 → 激活
  ├─ 用户管理：5 角色 RBAC 分配
  └─ 审计日志：按时间/用户/操作类型筛选
```

## 四、技术架构

### 4.1 技术栈

- **后端**：FastAPI + SQLAlchemy 2.0 异步 + Pydantic v2 + Alembic + JWT + Fernet 加密
- **前端**：Next.js 14.2.5（App Router）+ React 18.3.1 + Zustand + XState v5 + reactflow + react-virtuoso + Monaco Editor
- **AI 引擎**：自研 ReAct Agent（AgentEngine / Planner / Registry / Guardrail / Audit）
- **数据库**：PostgreSQL（+TimescaleDB）/ Redis / ChromaDB / Neo4j / SQLite（开发）
- **存储**：MinIO（对象存储）
- **工作流**：Nextflow + nf-core
- **生物信息**：Scanpy / BioPython / RDKit / cyvcf2 / gseapy / opacus
- **AI/ML**：litellm / DeepChem / PyTorch Geometric / DiffDock
- **隐私计算**：Flower（联邦学习）/ PySyft（隐私保护）/ DPSGD（差分隐私）
- **CI/CD**：GitHub Actions（backend-ci / frontend-ci / deploy）+ Docker 多阶段构建

### 5.2 覆盖率

### 5.3 安全加固

- 5 角色 RBAC 权限矩阵（16 工具 × 6 角色）
- Fernet 对称加密 LLM API Key
- JWT 认证 + 刷新令牌
- WebSocket 多级权限校验（owner_id + access_token 类型）
- 多级 ownership 校验（target→project→owner / molecule→target→project→owner）
- 长连接超时保护（max_conn_sec=1800）
- CPU 密集操作 asyncio.to_thread 包装
- 全操作审计日志（IP / User-Agent / Action / Resource）
- **API Key 不在源码 / 文档 / 提交包中明文出现**

## 六、社会价值（社会服务赛道）

### 6.1 直接社会价值

1. **降低药物研发成本**：传统新药研发平均 26 亿美元 / 10-15 年周期，本系统通过 AI 辅助靶点发现与老药新用扫描，可在数小时内完成传统数月的工作
2. **推动罕见病用药**：老药新用模块专门针对已获批药物重新匹配适应症，为罕见病患者提供希望
3. **赋能基层医疗**：临床医生可使用 AI 问答获取最新治疗策略，缩小城乡医疗差距
4. **促进多中心协作**：联邦学习让多家医院在不共享原始数据的前提下联合训练模型

### 6.2 间接社会价值

1. **数据合规示范**：CDISC SDTM + HL7 FHIR R4 + 知情同意管理，为医疗数据合规使用提供范本
2. **AI 伦理实践**：医疗红线规则 + Guardrail 安全护栏 + 全程审计，体现负责任 AI
3. **开源生态贡献**：集成 11 个开源工具，所有代码 MIT 协议开源
